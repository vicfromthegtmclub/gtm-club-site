Interactive diagnostic. It scores 8 outbound signals (engagers, profile views,
competitor connections, job changes, tech stack changes, hiring, website
visitors and custom signals) against your situation, then names the one to start
with this week, with the setup effort, the time to first reply, and what to do
next. The page itself is the tool, so opening this asset loads the test.
